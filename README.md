# GA4GH Passport & AAI Playground 

Deploy test ecosystems using GA4GH Passports and AAI to share data and govern data access.

Compose your test ecosystem with any combination of publicly available implementations and GA4GH Passport Playground implementations. Experiment with different architectures and focus on interoperability and governance, without running big workflows on large data sets.
